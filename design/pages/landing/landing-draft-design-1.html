It looks like CSS. There is no browser.

MOROK is a UI kit for macOS that draws the whole interface itself, through Metal. You style windows with CSS compiled at build time and change them by writing signals.

What it is, and what it is not

  • Native. Rust, Core Text and Metal 4.
  • Styled by CSS. 109 properties, compiled into tables at build time.
  • Driven by signals. A component runs once; a signal changes exactly what follows it.
  • Complete. Buttons, fields, tables, menus, dialogs — with keyboard and accessibility.
  • Not a web view. No browser and no JavaScript.
  • Not a wrapper. No AppKit controls under it.
  • Not cross-platform. macOS 26 on Apple Silicon.
  • Not all of CSS. A subset the compiler checks, with a diagnostic at the place.

How a window is written

// Rust: a component runs once
fn sign_in(mount: &mut Mount<'_>) -> ElementId {
    let name = mount.runtime().signal(String::new());
    let field = TextField::new(name).placeholder("Name").mount(mount);
    let button = Button::new("Sign in").primary().mount(mount);
    mount.element().class(CLASSES.form).child(field).child(button).id()
}
