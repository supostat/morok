OVERVIEW

It looks like CSS. There is no browser.

MOROK is a UI kit for macOS that draws the whole interface itself, through Metal. You style windows with CSS compiled at build time and change them by writing signals. This page is laid out the way an application of the kit is: a toolbar, a sidebar, a pane and a status bar.

WHAT IT IS
  • NativeRust, Core Text and Metal 4.
  • Styled by CSS109 properties and 7 states, compiled into tables at build time.
  • Driven by signalsA component runs once; a signal changes exactly what follows it.
  • CompleteButtons, fields, tables, menus, dialogs — with keyboard and accessibility.
WHAT IT IS NOT
  • A web viewNo browser and no JavaScript.
  • A wrapperNo AppKit controls under it.
  • Cross-platformmacOS 26 on Apple Silicon.
  • All of CSSA subset the compiler checks, with a diagnostic at the place.

A WINDOW IN CODE
// Rust: a component runs once
fn sign_in(mount: &mut Mount<'_>) -> ElementId {
    let name = mount.runtime().signal(String::new());
    let field = TextField::new(name).placeholder("Name").mount(mount);
    let button = Button::new("Sign in").primary().mount(mount);
    mount.element().class(CLASSES.form).child(field).child(button).id()
}
/* CSS: compiled at build time */
.form {
  display: flex;
  gap: var(--space-3);
  padding: var(--space-4);
  background-color: var(--color-surface);
}
