MOROK — a UI kit for macOS

Rust · Core Text · Metal 4

It looks like CSS. There is no browser.

MOROK draws the whole interface itself. You style windows with CSS compiled at build time and change them by writing signals.

01

Every pixel is the kit's own.

No AppKit controls and no web view: the kit lays out, shapes text and paints through Metal.

02

The look is a stylesheet.

109 properties and 7 states of CSS, compiled into tables when the application builds. What the compiler does not take, it refuses with a diagnostic at the place.

.form {
  display: flex;
  gap: var(--space-3);
  padding: var(--space-4);
  border-radius: var(--radius-md);
  background-color: var(--color-surface);
}
03

A component runs once.

It builds its elements and binds them to signals. From then on a signal that changes updates exactly what follows it.

fn sign_in(mount: &mut Mount<'_>) -> ElementId {
    let name = mount.runtime().signal(String::new());
    let field = TextField::new(name).placeholder("Name").mount(mount);
    let button = Button::new("Sign in").primary().mount(mount);
    mount.element().class(CLASSES.form).child(field).child(button).id()
}
