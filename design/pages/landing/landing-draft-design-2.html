A UI kit for macOS · Rust · Metal 4

It looks like CSS. There is no browser.

MOROK draws the whole interface itself. You style windows with CSS compiled at build time and change them by writing signals.

Read the guideGitHub

What you get

And what you do not.

Drawn through Metal

Rust, Core Text and Metal 4. No AppKit controls under it.

Styled by CSS

109 properties and 7 states, compiled into tables at build time.

Driven by signals

A component runs once; a signal changes exactly what follows it.

Keyboard and accessibility

Every component answers the pointer, the keys and an assistive technology.

Light and dark

Tokens hold both color schemes; a window follows the system.

Not a web view

No browser, no JavaScript, and not all of CSS: a subset the compiler checks. macOS only.

Components

Ten families and two whole screens in the catalog: cargo run -p morok-catalog.

How a window is written

A component in Rust, its look in CSS.

RustCSS
// A component runs once
fn sign_in(mount: &mut Mount<'_>) -> ElementId {
    let name = mount.runtime().signal(String::new());
    let field = TextField::new(name).placeholder("Name").mount(mount);
    let button = Button::new("Sign in").primary().mount(mount);
    mount.element().class(CLASSES.form).child(field).child(button).id()
}
